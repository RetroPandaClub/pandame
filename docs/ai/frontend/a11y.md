# Accessibility

Non-negotiable in every locale. `svelte-check` and the `eslint-plugin-svelte`
recommended rules catch part of it; the rest is on you.

## Copy

- New copy is a `$i18n.*` key ([`workflows/i18n.md`](./workflows/i18n.md)).
  Brand and product names (PandaMe, Internet Identity, ICP) are not wrapped.
- Engineer-facing logs and thrown messages are not user copy.
- No sentences glued with `+`: one key per phrase, `{name}` placeholders.

## Semantics

- `<button>` for actions, `<a>` for navigation, `<label>` for inputs, headings
  in order, landmarks (`nav`, `main`, `header`, `footer`).
- No clickable `<div>` / `<span>`. If one is unavoidable it needs `role`,
  `tabindex="0"` and Enter / Space handlers; a real element is almost always
  the answer, and so is avoiding `role="button"`.

## Labels and icons

- Every input has a `<label for>` or `aria-label` / `aria-labelledby`.
- Icon-only controls carry `aria-label` on the control, not on the icon.
- Decorative icons and images: `aria-hidden="true"` / `alt=""`. Meaningful
  images: an `alt` that says what they show.
- Reused SVGs live in [`$lib/components/icons/`](../../../src/lib/components/icons/);
  a one-off decorative SVG may stay inline.

## Focus and keyboard

- Never remove focus outlines.
- Dialogs build on [`Modal.svelte`](../../../src/lib/components/Modal.svelte)
  and [`Backdrop.svelte`](../../../src/lib/components/Backdrop.svelte) (Esc to
  close, keyboard-reachable close); sign-out uses
  [`LogoutConfirmModal.svelte`](../../../src/lib/components/LogoutConfirmModal.svelte).
- Focus order follows visual order in pick-one lists (`Tabs`, `VotePicker`,
  `PanelSizePicker`).

## Colour

- State is never colour alone: pair it with an icon, a label or a shape
  (`DealStatusIcon`, `DisputePhaseBadge`).
- Theme tokens only ([theming](./stack-and-patterns.md#styling-and-theming)).

## Pages and HTML

- Every route sets a localized `<title>` in `<svelte:head>`
  ([page composition](./stack-and-patterns.md#page-composition)); the one in
  [`src/app.html`](../../../src/app.html) is the fallback. Keep route titles,
  and give a new route one.
- `target="_blank"` always with `rel="noopener noreferrer"`.
- `{@html}` only for `*_html` i18n keys. There is no sanitiser; ask before
  rendering anything else as HTML.

## Checklist for every UI change

- [ ] Real `<button>` / `<a>` or an existing primitive.
- [ ] Every input labelled; every icon-only control named.
- [ ] Decorative icons hidden, images described.
- [ ] State conveyed by more than colour; no raw colours.
- [ ] External links carry `rel="noopener noreferrer"`.
- [ ] Copy through `$i18n.*`.
