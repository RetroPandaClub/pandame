# Workflow: add or rename copy

Keys live in [`src/lib/i18n/en.json`](../../../../src/lib/i18n/en.json);
[`scripts/i18n.ts`](../../../../scripts/i18n.ts) generates
[`src/lib/types/i18n.d.ts`](../../../../src/lib/types/i18n.d.ts) so
`$i18n.section.key` is typed. [`auto-update-i18n.yml`](../../../../.github/workflows/auto-update-i18n.yml)
reruns the generator on PRs touching `src/lib/i18n/**`.

| File                           | Role                                                                                     |
| ------------------------------ | ---------------------------------------------------------------------------------------- |
| `src/lib/i18n/en.json`         | The dictionary, grouped by namespace (`core`, `deals`, `detail`, `errors`, `profile`, …) |
| `src/lib/types/i18n.d.ts`      | Generated, never edited                                                                  |
| `src/lib/types/languages.ts`   | Supported locale codes (`'en'`)                                                          |
| `src/lib/stores/i18n.store.ts` | `i18n` store: `init`, `switchLang`, locale in `localStorage`                             |

## Add a key

1. Add it to `en.json` under the namespace of the screen or concept.
2. `npm run i18n` and commit the regenerated `i18n.d.ts`.
3. Use it: `{$i18n.section.key}` after `import { i18n } from '$lib/stores/i18n.store'`.
4. Placeholders are `{name}`, filled with `String#replace` at the call site,
   one call per placeholder:
   `$i18n.detail.panel_size_value.replace('{n}', String(panelSize))`
   ([`deals/[deal_id]/+page.svelte`](../../../../src/routes/deals/[deal_id]/+page.svelte)).
   Pluralisation needs a question first.
5. Keys ending in `_html` render with `{@html}` and an inline
   `<!-- eslint-disable-next-line svelte/no-at-html-tags -->`; only for text
   you control in the dictionary.

## Rename a key

Rename it in `en.json`, update every `$i18n.old.path` in `src/` and `e2e/`,
`npm run i18n`; `npm run check` reports any call site left.

## Add a locale

Ask first. Then: the code in `languages.ts`, `src/lib/i18n/<code>.json` with
exactly the keys of `en.json`, a `case` in `loadLang` in `i18n.store.ts`, and
this page updated.

## Do not

- Edit `i18n.d.ts` by hand.
- Add English to a component "for now".
- Build a sentence from several keys with `+`.
